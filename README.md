# The Wellness Edit — Storefront

A responsive, front-end-only e-commerce site for a school e-business project. Plain HTML, CSS and JavaScript: no database, no backend, no build step.

## Run locally
```
npm run dev
```
Then open http://localhost:3000. (Requires Node.js. No `npm install` needed.) You can also just double-click `index.html`.

## Deploy to Vercel
1. Push this folder to a GitHub repo (this folder should be the repo root).
2. On vercel.com, choose **Add New → Project** and import the repo.
3. Nothing to configure — `vercel.json` already tells Vercel it's a static site.
4. Click **Deploy**.

## Pages
Home · Shop · Product details · About & Team · Ingredients · Journal · FAQ · Contact · Business policies · Privacy policy · Security · Bag/Checkout

No plug-ins are used: multi-currency prices and Spanish/French text are plain text. The optional demo cart is saved in localStorage.
